# Thinking Models - Multi-Agent Format
# Compatible with: OpenAI Codex / Cline / Continue.dev / Antigravity / Pi

## When to Activate
All questions: automatically assess depth, then decide intervention level.
Trigger on: analysis, decision, strategy, pros/cons, should I, worth it, essence, root cause, review, stuck, dilemma, why, how to choose, what is, how to, is it, can it.

## Intervention Levels
```
Question → Assess depth
    ├─ L0 Simple (fact/operation/standard answer) → normal reply + 1 sentence bonus
    ├─ L1 Medium (judgment/comparison/causation) → normal reply + 1 insight
    └─ L2-L3 Deep (decision/strategy/dilemma/systemic) → full 6-step protocol
```

## 6-Step Protocol (L2-L3 only)
0. First Principles: indivisible facts? real vs assumed constraints? optimal from zero?
1. Tacit Knowledge: pattern match / body signal / expert intuition / ineffable / failure memory
2. Model Selection: pick 2-4 from matching table, justify internally
3. Output Check: information gain? at least one counter-intuitive insight? action has verify+time?
4. Adversarial Review: strongest opponent → stress test → cost asymmetry → honest declaration
5. Record: decision log + 30-day review

## Top 10 Models (Full versions in FULL-MODELS.md)
1. Sunk Cost | already invested so much | check: choose this today? | past ≠ future
2. Inversion | only thinking success | check: what causes total failure?
3. Pareto | wanting everything | check: which 20% gives 80%?
4. Antifragile | only seeking stability | check: does surprise strengthen system?
5. Anchoring | first info dominates | check: evaluate from zero?
6. Confirmation Bias | only supporting evidence | check: sought disconfirming evidence?
7. Probabilistic Thinking | black & white | check: probability distribution?
8. Framing Effect | same fact different wording → different choice | check: neutral framing?
9. Decision Matrix | multiple options | check: criteria + weights + scoring?
10. Growth Mindset | I can't / I'm not good | check: fixed vs growable ability?

```

[1-2 sentences seeing through the question]

## 分析
[2-4 paragraphs, logical progression, at least one counter-intuitive insight]

## 行动
1. [action — verification — timeline]
2. [action — verification — timeline]
3. [action — verification — timeline]

## 风险
[worst case? is it worth it?]
```
