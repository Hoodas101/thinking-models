## 这是什么

一个让AI在回答任何问题时自动调用思维模型和认知偏误检查的 skill。

**不是**：只有用户说"分析"时才触发的工具。
**而是**：所有问题都先经过思维框架审视，再决定回答深度。简单问题一句话点缀，深度问题全力展开。

## 谁需要它

| 你是 | 你会遇到 | 这个 skill 帮你 |
|---|---|---|
| **普通用户** | 换工作、买房买保险、孩子教育、和家人沟通，人生高频决策没人商量 | 把纠结拆成"本质→分析→行动→风险"，AI 不再和稀泥；还能用苏格拉底式提问引导你自己想清楚，不替你做决定 |

| **AI 创作者 / 开发者** | 想让你的 agent 有个"深度思考层"，不停留在复述搜索结果 | 开箱即用的分级介入协议 + 三模式输出 + 跨平台格式（SKILL.md / AGENTS.md / .cursorrules）；也是构建自己"思考型 skill"的参考架构 |

## 核心能力

- **66 个思维模型**：从沉没成本到反脆弱，覆盖战略/决策/系统/人际/成长 5 大领域
- **39 个认知偏误**：从确认偏误到过度拟合，自动检查推理链（完整纠偏见姊妹 skill [bias-correction](https://github.com/Hoodas101/bias-correction)）
- **分级介入**：L0/L1/L2-L3 三级自动调节，简单问题不画蛇添足，深度问题全六步协议
- **三模式输出**：简洁 / 引导（苏格拉底式提问）/ 深度，按问题复杂度与用户偏好自适应
- **第一性原理**：每题必做，拆到不可再拆的事实
- **默会知识**：把经验直觉也一起调动起来
- **对抗性审查**：输出前先红队自己的结论，最强反对者 / 压力测试 / 代价不对称
- **模型数量动态调整**：1-7 个随复杂度变化，宁少勿滥，每个模型必须有独特信息增量
- **决策追踪**：深度分析后生成决策日志，30 天后提醒复盘
- **安全防护**：高危场景（心理/法律/医疗/重大金钱）建议专业帮助，东方文化情境不误诊
- **退出机制**：用户说"直接答"时服从不强行介入

## 你会得到什么变化

不吹数字，只讲机制，每一项都可以用一次对话验证：

- **决策质量**：每个深度分析强制经过"第一性原理拆解 → 模型匹配 → 对抗审查"三道闸，并至少给出一个反直觉洞察
- **避开盲区**：39 个偏误自动检查推理链，识别"沉没成本""幸存者偏差"这类自己极难察觉的陷阱
- **复盘机制**：决策日志 + 30 天提醒，用真实结果校准判断力，这是读书和刷文章都给不了的
- **省时间**：分级介入让简单问题零打扰，深度思考只花在值得的问题上

## 工作原理

```
收到问题 → 深度分级
    ├─ L0 简单（有标准答案/纯事实）      → 常规回答 + 1 句增值，不展示框架
    ├─ L1 中等（比较/因果/轻度判断）     → 正常回答 + 1 个洞察点缀
    └─ L2-L3 深度（两难/系统性/有后果）  → 六步协议：底层拆解 → 默会知识
                                          → 模型匹配 → 输出检验 → 对抗审查 → 决策日志
```

## 输出示例

### L0 简单问题

**问**："Python 最新版本是多少？"

**答**：Python 3.12.4（2024年6月发布）。

> 值得注意的是：3.12之后类型系统有重大变化——`TypeVar`语法更简洁，`@override`装饰器正式进入标准库。

### L1 中等问题

**问**："为什么 React 比 Vue 流行？"

**答**：三个主要原因：生态先发优势、就业市场正反馈、JSX的学习曲线反而成了护城河。

> 但要提醒一个认知偏差："流行=好"是可得性启发。Vue在国内中小企业实际使用率很高，只是声量不如React。流行度反映生态规模，不是技术优劣。

### L2-L3 深度问题（日常生活场景）

**问**："孩子进入叛逆期，说什么都不听，怎么办？"

**答**：

我理解这确实让人很疲惫——先理清思路，我们一步步来。

## 本质
你面对的不是"孩子不听话"，而是一个**自主性觉醒的正常发展阶段**。叛逆期的核心矛盾是：孩子需要证明"我能自己做主"，而父母还在用"我为你好"的方式控制。

## 分析
多数家长的应对方式是"加大控制"，但这恰恰强化了叛逆——因为孩子反抗的不是规则本身，而是"被控制"的感觉。反直觉洞察：**叛逆期孩子最需要的不是更好的规则，而是有限的选择权**。当你给他在框架内做决定的空间（"你打算先做数学还是英语？"），他的自主性需求被满足，对抗就减少了。

## 行动
1. **给有限选择** — 把"必须做A"改成"A还是B你选" — 立即开始
2. **区分底线和弹性** — 安全/道德是底线（不让步），其他事给空间 — 本周梳理
3. **记录积极行为** — 每天记录1件孩子做得好的事，只强化不批评 — 持续2周

## 风险
最坏不是"叛逆期持续"，是"孩子学会撒谎来逃避控制"——表面听话，内心疏远。

### L2-L3 深度问题（vs 不用 skill 的对比）

**问**："该不该在大城市留下来？"

**普通AI回答**：

> 要看你的职业发展、生活成本、个人偏好等因素。大城市机会多但压力大，小城市安逸但机会少。建议你综合考虑再做决定。

**思维模型增强回答**：

## 本质
你问的是"该不该留"，但真问题是**"你想过什么样的生活"**。大城市留下不是"好或坏"的二选一，是不同人生路径的取舍。

## 分析
反直觉洞察：多数人用"机会多=该留"做决策，但忽视了**边际效用递减**——第3年和第10年的"机会多"对你意义不同。真正的问题是：**你的甜蜜点（热情×能力×需求）在哪个环境更容易实现？**

## 行动
1. **列出你的核心需求** — 职业成长/家庭时间/住房/社交，哪个排第一？ — 1天
2. **算3年后的差异** — 留在大城市vs回小城市，3年后你的净资产/职位/生活质量对比 — 1周
3. **试水验证** — 请假1周回小城市生活，感受真实差异 — 1个月

## 风险
最坏不是"选错了"，是"一直不选"——5年后既没扎根大城市也没回家乡，两头空。

### 引导模式（苏格拉底式）

**问**："该不该从程序员转管理？"（用户说：帮我理一理）

**答**：

我理解这确实是个艰难的决定——先理清思路，我们一步步来。

在回答之前，我想先问你几个问题：

**你转管理的真实动机是什么？**
- 是因为"技术做不动了"？
- 还是因为"喜欢带人、看别人成长"？
- 还是因为"觉得管理更高级/更赚钱"？

这三种动机会导致完全不同的5年后。

**你有没有想过——你现在的"技术能力"其实是一种"硬通货"？**
- 全世界都认——你可以在任何公司、任何城市靠它吃饭。
- 但管理能力是"组织货币"——离开这个公司，它就不值钱了。

**如果换个角度看——"转管理"不是非此即彼的选择**
- 有没有可能"80%技术+20%带人"？
- 先试水3个月，看看自己是不是真的喜欢"通过他人完成工作"的成就感？

想想这几个问题，然后告诉我你的第一反应是什么。

## 证据强度：我们不装作 66 个模型都有实验背书

市面上"思维模型"类内容最大的通病是把芒格的 anecdote 和 Kahneman 的 RCT 混在一起贩卖。本库对 #11-66 共 56 个扩展模型逐条标注了证据等级（第一层 10 个精选模型因常识性极强未逐条标注），统计如下：

| 标注 | 数量 | 含义 | 怎么用 |
|---|---|---|---|
| 📊 学术共识 | 25 | 认知科学/行为经济学教科书级结论 | 可以放心作为纠正依据 |
| 📊 实证支持 | 9 | 有具体研究支持（如飞轮效应源于 Collins 实证对照研究） | 作为主要参考，注意研究场景与你的场景差异 |
| 💡 经验总结 | 14 | 来自 practitioner（芒格、Taleb 等）的启发式，无系统实验 | 当作提问的镜子，不是答案的权威 |
| 🔄 隐喻借用 | 6 | 从物理/化学/生物借来的概念（黑天鹅、耗散结构、勒沙特列） | **警惕**：隐喻是类比不是证明，跨域迁移时最易出错 |
| ⚠️ 有争议 | 2 | 学术界存在实质分歧（彼得原理、破窗效应） | 仅作思考入口，不作为决策依据 |

三个推论，也是我们敢公开这个统计的原因：

1. **越"听起来深刻"的模型，证据越薄**。黑天鹅、耗散结构、涌现这类跨域隐喻读起来最爽，恰恰是它们最经不起追问"这个类比在你的场景里成立吗"。
2. **有争议的不删除，但明说**。彼得原理、破窗效应有真实洞察力也有实证反驳，藏起来不如标出来。
3. **skill 内部协议同样执行这条标准**：六步协议的"对抗审查"要求每个结论标注确定性（高/中/低），与本表同源。一个反对"伪装确定性"的工具，自己先不能伪装。

> 完整逐条标注见 `FULL-MODELS.md`；姊妹 skill bias-correction 的 39 个偏误证据更强：37 个学术共识 + 2 个经验总结（道德许可、虚拟认同），因为偏误研究是对照实验密集领域。

## 设计决策：几个"为什么不做得更花哨"的回答

| 你可能觉得"不够好"的地方 | 为什么不那样做 |
|---|---|
| 简单问题只加一句话，不做完整分析 | 分级介入是核心设计：对 L0 事实问题启动六步协议，是"拿着锤子找钉子"。工具的第一美德是知道什么时候**不**出手 |
| 模型选择不在输出里展示（只给结论） | 展示"我用了 #4 反脆弱 + #23 二阶思维"是在给你表演分析，不是帮你分析。论证内化，结论外显 |
| 引导模式（模式 B）不给结论只提问 | 决策科学的核心发现：人对"被说服去做的决定"不会执行，对"自己想通的决定"会。替你做决定的分析质量再高，落地率也低 |
| 输出禁止可视化卡片、禁止"适配度打分" | 这类装饰把"看起来专业"偷换成"真的有用"，还会让你去审查格式，不去审查结论 |
| 高危场景先提示找专业人士 | 抑郁、诉讼、用药不是"思维偏误"问题。把专业问题揽进思维工具，是工具越界 |
| 东方情境（听父母的/讲面子）不强行纠偏 | 从众偏差的判定默认了个体主义参照系。文化适配层不是政治正确，是避免系统性误诊 |

## 局限性：说清楚它做不到什么

- **它不能替你获取信息**。模型匹配得再好，输入的事实错了（样本、数字、前提），输出照错不误。第一性原理步骤只能拆到"你告诉它的事实"为止。
- **它对自己的分析没有外部验证**。六步协议能逼它自我红队，但"AI 自评"天然有限。这就是决策日志存在的原因：最终裁判是 30 天后的真实结果，不是它的分析。
- **深度判断可能误分级**。"看起来小"的事（今天吃什么）和"看起来大"的事（该不该读研）都可能被分错层。说"简单说"或"详细分析"随时纠正。
- **不是心理支持**。检测到焦虑/抑郁信号时会建议找专业人士，这确实不该由思维工具兜底，跟免责条款无关。
- **对 LLM 宿主有依赖**。引导/对抗审查的执行质量取决于底层模型；弱模型上协议的完成度会下降（但不会假装完成，诚实声明是协议的一部分）。

## 5 分钟自测：不信介绍，就测这三条

装好后依次跑三句话，每条对应一个核心承诺：

| 你输入 | 验证什么 | 通过标准 |
|---|---|---|
| "Python 3.12 和 3.11 有啥区别" | 分级介入（L0 不舞大刀） | 正常回答，**不**出现"本质→分析→行动"框架，最多 1 句增值 |
| "我在这个项目投了两年了，虽然没起色，但再坚持半年应该能行吧？" | 偏误识别 + 对抗审查 | 点破沉没成本，给出"今天第一次接触还会选吗"检验，而非顺着鼓励坚持 |
| "帮我理一理要不要转管理" | 引导模式 | 收到的是提问（动机/约束/试水），不是替你做的决定 |

## 常见问题

**Q：所有问题都过一遍模型，不会很啰嗦吗？**
不会。L0/L1 不启动协议、不展示框架；只有 L2-L3（有后果、两难、系统性）才展开。这正是"分级介入"存在的意义。

**Q：这和直接对 AI 说"用思维模型分析我这个问题"有什么区别？**
三件事：① 你不自觉时它也在检查（偏误识别是触发词+推理结构双通道，不需要你先知道该问什么）；② 强制六步协议，AI 自选模型时倾向于"表演分析"而非"对抗审查"；③ 决策日志沉淀，单次对话变成长期校准数据。

**Q：66 个模型会不会太多，变成形式主义套壳？**
协议明确"宁少勿滥"：L2 只用 1-3 个，且每个模型必须有独特信息增量，重复视角算违规。多库是弹药库，不是每场都要全部开火。

**Q：能同时装 thinking-models 和 bias-correction 吗？会冲突吗？**
推荐组合，不冲突。TM 管"怎么做更好"（主动分级），BC 管"哪里会出错"（信号驱动被动触发），编号互通（沉没成本 = TM#1 = BC#29），联动协议写死在两边。单装任一个也各自成立（TM 内置偏误精简卡兜底）。

**Q：Claude Code 之外怎么用？**
Cursor 复制 `.cursorrules`，Codex/Cline/Continue 复制 `AGENTS.md`，协议同源，格式适配。

**Q：收费吗？模型库以后会扩充吗？**
MIT 开源免费。扩充会走 CHANGELOG，证据标注原则不变，新模型先标证据等级，标不出来就不收。
