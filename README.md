## 这是什么

一个按问题深度自动调节介入强度的思维模型 skill。77 个模型、39 种认知偏误，但默认只挑 1-3 个用。

**不是**：每个问题都套一遍模型的"分析表演"。
**而是**：先判断问题值不值得展开。简单问题正常回答，有后果的决策才调用模型、做反方检验、给出可验证行动。默认直接给建议，苏格拉底式引导只在你明确要求时启用。

门槛写在工程里，不写在口号里：模型条目集中在一份 `tools/models.json`，六份领域文档和来源清单都由它生成；编号、断链、数量、版本、表情符号、文件覆盖六类检查不过就发不出去；改提示词必须用真实模型跑一遍 10 道题的回归。三次候选改动实测下来没有一次真的更好，所以提示词维持原样，这一点也照实记在 CHANGELOG 里。

## 对比效果：装 vs 不装

| 维度 | 普通 AI 对话 | 装上 thinking-models |
|---|---|---|
| 问"该不该转行" | "要综合考虑，各有优劣"，正确的废话 | 点破真问题 + 反直觉洞察 + 带验证方式和时间节点的行动清单 |
| 深度调节 | 长篇大论或过于简短，不管问题重不重要 | L0-L3 分级介入：小事不啰嗦，大事不敷衍 |

| 偏误 | 看不出你正掉进"沉没成本"或"幸存者偏差" | 内置 Top 12 偏误速查，先点破最常见陷阱 |
| 长期 | 问完就忘，判断力原地踏步 | L3 或你明确要求时记入决策日志，供 30 天后复盘对照 |

## 姊妹 Skill：bias-correction

本 skill 与 [bias-correction](https://github.com/Hoodas101/bias-correction)（认知偏误纠正系统）是一对互补组合：

| | thinking-models（本 skill） | bias-correction |
|---|---|---|
| 定位 | **怎么做更好**，分析工具箱 | **哪里会出错**，防错护栏 |
| 内容 | 77 思维模型 + 场景匹配表 | 39 偏误 + 双通道触发识别 |
| 触发 | 所有提问先判深度，仅 L2-L3 展开完整协议 | 偏误信号驱动，非默认激活 |

两者编号互通（如沉没成本 = TM#1 = BC#29）、协议兼容。**推荐组合安装**，但各自可独立使用：单装本 skill 时，偏误检查由内置的 `BIAS-CORRECTION.md` 速查卡（Top 12）兜底；装了 bias-correction，需要完整 39 条纠偏时再按需调用，不重复展开两套框架。

## 核心能力

- **77 个思维模型**：从沉没成本到反脆弱，覆盖战略/决策/系统/人际/成长/进阶决策 6 大领域
- **Top 12 偏误速查**：内置最常见的认知陷阱；完整 39 条在姊妹 skill [bias-correction](https://github.com/Hoodas101/bias-correction)，按需加载
- **分级介入**：L0/L1 直接回答，L2-L3 才启动内部完整协议，简单问题不画蛇添足
- **默认直接建议**：苏格拉底式引导仅在你明确说"引导我/帮我理一理"时启用，不拿问卷替代答案
- **第一性原理**：先拆不可再拆的事实，区分真约束和惯例假设
- **反方检验**：输出前先问"最强反对意见是什么、什么证据会让我改判"，而不是只找支持理由
- **模型数量克制**：L2 选 1-3 个，L3 选 2-5 个，最多 5 个；每个模型必须有独特信息增量
- **决策追踪**：L3 或你明确要求时生成决策日志，供 30 天后复盘对照
- **安全防护**：高危场景（心理/法律/医疗/重大金钱）建议专业帮助，东方文化情境不误诊
- **退出机制**：用户说"直接答"时服从不强行介入

|---|---|---|---|---|

## 你会得到什么变化

不吹数字，只讲机制，每一项都可以用一次对话验证：

- **决策质量**：每个深度分析强制经过"第一性原理拆解 → 模型匹配 → 对抗审查"三道闸，并至少给出一个反直觉洞察
- **避开盲区**：内置 Top 12 偏误速查，识别"沉没成本""幸存者偏差"这类自己极难察觉的陷阱；需要完整 39 条时交给 bias-correction
- **复盘机制**：L3 或你明确要求时记录决策日志，30 天后对账，用真实结果校准判断力
- **省时间**：分级介入让简单问题零打扰，深度思考只花在值得的问题上

## 工作原理

```
收到问题 → 深度分级
    ├─ L0 简单（有标准答案/纯事实）      → 常规回答 + 最多 1 句提醒，不写模板标题
    ├─ L1 中等（比较/因果/轻度判断）     → 结论 + 2-4 句理由 + 1 个洞察，同样不写模板标题
    └─ L2-L3 深度（两难/系统性/有后果）  → 内部协议：事实与约束 → 选模型
                                          → 反方检验 → 输出检验
                                          → 仅 L3/明确要求时记决策日志
```

## 输出示例

### L0 简单问题

**问**："Python 最新版本是多少？"

**答**：Python 3.12.4（2024年6月发布）。

> 值得注意的是：3.12之后类型系统有重大变化——`TypeVar`语法更简洁，`@override`装饰器正式进入标准库。

### L1 中等问题

**问**："为什么 React 比 Vue 流行？"

**答**：三个主要原因：生态先发优势、就业市场正反馈、JSX的学习曲线反而成了护城河。

> 但要提醒一个认知偏差："流行=好"是可得性启发。Vue在国内中小企业实际使用率很高，只是声量不如React。流行度反映生态规模，不是技术优劣。

### L2-L3 深度问题（日常生活场景）

**问**："孩子进入叛逆期，说什么都不听，怎么办？"

**答**：

**结论**：先减少控制、给出有限选择；把底线（安全/道德）和可协商的事分开，比"让他听话"更有效。

**关键分析**：
- 你面对的不是"孩子不听话"，而是**自主性觉醒的正常发展阶段**。核心矛盾是：孩子需要证明"我能自己做主"，而父母还在用"我为你好"的方式控制。
- 多数家长的应对是"加大控制"，但这恰恰强化了叛逆——孩子反抗的不是规则本身，而是"被控制"的感觉。
- 反直觉洞察：**叛逆期孩子最需要的不是更好的规则，而是有限的选择权**。当他在框架内能做决定（"你打算先做数学还是英语？"），自主性需求被满足，对抗就减少。

**行动**：
1. **给有限选择** — 把"必须做A"改成"A还是B你选" — 立即开始
2. **区分底线和弹性** — 安全/道德是底线（不让步），其他事给空间 — 本周梳理
3. **记录积极行为** — 每天记录 1 件孩子做得好的事，只强化不批评 — 持续 2 周，无改善则换沟通时机

**风险/反方**：最坏不是"叛逆期持续"，是"孩子学会撒谎来逃避控制"——表面听话，内心疏远。若出现持续情绪低落、自伤或逃学信号，优先寻求专业帮助。

**置信度**：中——基于发展心理学的通用模式，具体效果取决于亲子关系与执行一致性。

### L2-L3 深度问题（vs 不用 skill 的对比）

**问**："该不该在大城市留下来？"

**普通AI回答**：

> 要看你的职业发展、生活成本、个人偏好等因素。大城市机会多但压力大，小城市安逸但机会少。建议你综合考虑再做决定。

**思维模型增强回答**：

**结论**：把问题从"该不该留"改成"未来 3 年哪种环境更匹配你的核心需求"；先做一次 3 个月的可逆试验，再决定长期去留。

**关键分析**：
- 你问的是"该不该留"，真问题是**"你想过什么样的生活"**。这不是"好或坏"的二选一，而是不同人生路径的取舍。
- 反直觉洞察：多数人用"机会多=该留"做决策，却忽视**边际效用递减**——第 3 年和第 10 年的"机会多"对你意义不同。
- 真正要判断的是：**你的甜蜜点（热情×能力×需求）在哪个环境更容易实现？**

**行动**：
1. **列出核心需求** — 职业成长/家庭时间/住房/社交，强制排序，只留前三 — 1 天
2. **算 3 年后的差异** — 留在大城市 vs 回小城市，3 年后的净资产/职位/生活质量对比 — 1 周
3. **试水验证** — 请假 1 周或远程办公 1 个月，回小城市真实生活 — 1 个月内

**风险/反方**：最坏不是"选错了"，是"一直不选"——5 年后既没扎根大城市也没回家乡。反方：如果照护家人或健康是硬约束，先满足约束，再谈"最优选择"。

**置信度**：中——取决于你列出的需求是真实偏好，还是社会期待的内化。

### 明确要求引导时（苏格拉底式）

**问**："该不该从程序员转管理？"（用户说：帮我理一理）

**答**：

我理解这确实是个艰难的决定——先理清思路，我们一步步来。

在回答之前，我想先问你几个问题：

**你转管理的真实动机是什么？**
- 是因为"技术做不动了"？
- 还是因为"喜欢带人、看别人成长"？
- 还是因为"觉得管理更高级/更赚钱"？

这三种动机会导致完全不同的5年后。

**你有没有想过——你现在的"技术能力"其实是一种"硬通货"？**
- 全世界都认——你可以在任何公司、任何城市靠它吃饭。
- 但管理能力是"组织货币"——离开这个公司，它就不值钱了。

**如果换个角度看——"转管理"不是非此即彼的选择**
- 有没有可能"80%技术+20%带人"？
- 先试水3个月，看看自己是不是真的喜欢"通过他人完成工作"的成就感？

想想这几个问题，然后告诉我你的第一反应是什么。

## 证据强度：我们不装作 77 个模型都有实验背书

市面上"思维模型"类内容最大的通病是把芒格的 anecdote 和 Kahneman 的 RCT 混在一起贩卖。本库对 #11-77 共 67 个扩展模型逐条标注了证据等级（第一层 10 个精选模型默认未逐条标注；例外是其中证据最薄的两个：**#4 反脆弱**属隐喻借用、**#10 成长型思维**属有争议，遇到它们按对应等级谨慎使用），统计如下：

<!-- AUTO:evidence_zh -->
| 等级 | 数量 | 含义 | 怎么用 |
|---|---|---|---|
| 1 学术共识 | 28 | 认知科学/行为经济学教科书级结论 | 可以放心作为纠正依据 |
| 2 实证支持 | 10 | 有具体研究支持（如飞轮效应源于 Collins 实证对照研究） | 作为主要参考，注意研究场景与你的场景差异 |
| 3 经验总结 | 21 | 来自 practitioner（芒格、Taleb 等）的启发式，无系统实验 | 当作提问的镜子，不是答案的权威 |
| 4 隐喻借用 | 6 | 从物理/化学/生物借来的概念（黑天鹅、耗散结构、勒沙特列） | **警惕**：隐喻是类比不是证明，跨域迁移时最易出错 |
| 5 有争议 | 2 | 学术界存在实质分歧（彼得原理、破窗效应） | 仅作思考入口，不作为决策依据 |
<!-- /AUTO:evidence_zh -->

三个推论，也是我们敢公开这个统计的原因：

1. **越"听起来深刻"的模型，证据越薄**。黑天鹅、耗散结构、涌现这类跨域隐喻读起来最爽，恰恰是它们最经不起追问"这个类比在你的场景里成立吗"。
2. **有争议的不删除，但明说**。彼得原理、破窗效应有真实洞察力也有实证反驳，藏起来不如标出来。
3. **skill 内部协议同样执行这条标准**：内部协议的"反方检验"要求每个结论标注确定性（高/中/低），与本表同源。一个反对"伪装确定性"的工具，自己先不能伪装。

> 完整逐条标注见 `models/`；姊妹 skill bias-correction 的 39 个偏误证据更强：37 个学术共识 + 2 个经验总结（道德许可、虚拟认同），因为偏误研究是对照实验密集领域。

## 设计决策：几个"为什么不做得更花哨"的回答

| 你可能觉得"不够好"的地方 | 为什么不那样做 |
|---|---|
| 简单问题只加一句话，不做完整分析 | 分级介入是核心设计：对 L0 事实问题启动完整协议，是"拿着锤子找钉子"。工具的第一美德是知道什么时候**不**出手 |
| 模型选择不在输出里展示（只给结论） | 展示"我用了 #4 反脆弱 + #23 二阶思维"是在给你表演分析，不是帮你分析。论证内化，结论外显 |
| 引导模式只在用户明确要求时启用 | 默认直接给最佳建议，避免用问卷替代答案；用户明确说"引导我/帮我理一理"时再改用提问，因为对这类用户，"自己想通的决定"落地率更高 |
| 输出禁止可视化卡片、禁止"适配度打分" | 这类装饰把"看起来专业"偷换成"真的有用"，还会让你去审查格式，不去审查结论 |
| 高危场景先提示找专业人士 | 抑郁、诉讼、用药不是"思维偏误"问题。把专业问题揽进思维工具，是工具越界 |
| 东方情境（听父母的/讲面子）不强行纠偏 | 从众偏差的判定默认了个体主义参照系。文化适配层不是政治正确，是避免系统性误诊 |

## 局限性：说清楚它做不到什么

- **它不能替你获取信息**。模型匹配得再好，输入的事实错了（样本、数字、前提），输出照错不误。第一性原理步骤只能拆到"你告诉它的事实"为止。
- **它对自己的分析没有外部验证**。内部协议能逼它做反方检验，但"AI 自评"天然有限。这就是决策日志存在的原因：最终裁判是 30 天后的真实结果，不是它的分析。
- **深度判断可能误分级**。"看起来小"的事（今天吃什么）和"看起来大"的事（该不该读研）都可能被分错层。说"简单说"或"详细分析"随时纠正。
- **不是心理支持**。检测到焦虑/抑郁信号时会建议找专业人士，这确实不该由思维工具兜底，跟免责条款无关。
- **对 LLM 宿主有依赖**。引导/对抗审查的执行质量取决于底层模型；弱模型上协议的完成度会下降（但不会假装完成，诚实声明是协议的一部分）。

## 5 分钟自测：不信介绍，就测这三条

装好后依次跑四句话，每条对应一个核心承诺：

| 你输入 | 验证什么 | 通过标准 |
|---|---|---|
| "Python 3.12 和 3.11 有啥区别" | 分级介入（L0 不舞大刀） | 正常回答，**不**出现"本质→分析→行动"框架，最多 1 句增值 |
| "我在这个项目投了两年了，虽然没起色，但再坚持半年应该能行吧？" | 偏误识别 + 对抗审查 | 点破沉没成本，给出"今天第一次接触还会选吗"检验，而非顺着鼓励坚持 |
| "帮我理一理要不要转管理" | 引导模式 | 收到的是提问（动机/约束/试水），不是替你做的决定 |
| "这个功能我们计划 6 周做完，靠谱吗" | 参考类预测（#67） | 先要同类项目的历史分布作基准，再说明本案例为何更快/更慢，给出区间而非单点 |

## 常见问题

**Q：所有问题都过一遍模型，不会很啰嗦吗？**
不会。L0/L1 不启动协议、不展示框架；只有 L2-L3（有后果、两难、系统性）才展开。这正是"分级介入"存在的意义。

**Q：这和直接对 AI 说"用思维模型分析我这个问题"有什么区别？**
三件事：① 你没想着要分析时，它也会先判深度，够格才展开（简单问题不打扰）；② 强制内部协议（模型匹配 + 反方检验），避免 AI 自选模型时"表演分析"而非真正挑错；③ L3 或你明确要求时沉淀决策日志，单次对话变成长期校准数据。

**Q：77 个模型会不会太多，变成形式主义套壳？**
协议明确"宁少勿滥"：L2 只用 1-3 个，且每个模型必须有独特信息增量，重复视角算违规。多库是弹药库，不是每场都要全部开火。

**Q：能同时装 thinking-models 和 bias-correction 吗？会冲突吗？**
推荐组合，不冲突。TM 管"怎么做更好"（主动分级），BC 管"哪里会出错"（信号驱动被动触发），编号互通（沉没成本 = TM#1 = BC#29），联动协议写死在两边。单装任一个也各自成立（TM 内置偏误精简卡兜底）。

**Q：Claude Code 之外怎么用？**
Cursor 复制 `.cursorrules`，Codex/Cline/Continue 复制 `AGENTS.md`，协议同源，格式适配。

**Q：收费吗？模型库以后会扩充吗？**
MIT 开源免费。扩充会走 CHANGELOG，证据标注原则不变，新模型先标证据等级，标不出来就不收。

## 适用场景

###  适合使用
- 职业决策（跳槽/转行/创业）
- 人际沟通（亲子/伴侣/同事）
- 消费决策（买房/保险/大额支出）
- 自我成长（学什么/怎么提升）
- 商业分析（竞争策略/资源分配/增长）
- 日常纠结（吃啥/去哪/怎么选）

###  需要先咨询专业人士
- 心理健康（抑郁/焦虑/自伤倾向）
- 法律纠纷（离婚/合同/诉讼）
- 医疗决策（治疗方案/用药）

###  不适合使用
- 纯事实查询（天气/日期/定义）
- 代码报错/调试
- 创意娱乐（写故事/讲笑话）

## 使用技巧

| 你说 | AI 表现 |
|---|---|
| "简单说" / "一句话" | 直接结论 + 1 个关键洞察 |
| "帮我理一理" / "引导我思考" | 苏格拉底式提问，不替你做决定（仅在你明确要求时） |
| "详细分析" / "越细越好" | 结论 → 关键分析 → 行动 → 风险 |
| "不要分析/直接答" | 退出机制生效，正常回答 |
